# Banking Analytics — SQL & Power BI

## Project Overview

This project is a Banking Analytics solution developed using **MySQL, SQL and Power BI**.

The objective of this project is to analyze customers, accounts, transactions, loans, branches and employees and convert the data into meaningful business insights through an interactive Power BI dashboard.

## Tools & Technologies

* MySQL
* SQL
* Power BI
* DAX
* Power Query
* Data Modeling
* Data Visualization

## Database Tables

The project contains six main tables:

* Customers
* Accounts
* Transactions
* Loans
* Branches
* Employees

## Power BI Dashboard

### 1. Banking Overview

Provides an overall view of the banking business using key performance indicators such as:

* Total Customers
* Total Accounts
* Total Account Balance
* Total Transactions
* Total Transaction Amount
* Total Loans
* Total Loan Amount

### 2. Transaction Analytics

Analyzes transaction activity, transaction amounts and transaction trends to understand overall banking transaction performance.

### 3. Customer Analytics

Provides insights into customer distribution and customer-related banking activity.

### 4. Loan Portfolio & Risk

Analyzes the loan portfolio and provides insights into loan amounts and risk-related information.

### 5. Branch & Employee Performance

Analyzes branch and employee performance using metrics such as:

* Total Branches
* Total Employees
* Average Employee Salary
* Customers per Branch
* Employees per Branch
